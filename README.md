### Currently learning: Rust

I'm learning Rust, and I learn best by building. My current project is **PlaylistHistory**: a Rust API to track and archive the history of editorial playlists from music platforms. Platforms only show a snapshot of their playlists, so it records how they change over time (which tracks come in, which drop out, and when) and exposes that historized data through an API.

It's also my Rust playground, so the stack isn't fully settled yet: right now it's built around **Axum** for the web API and **sqlx** for database access. [Check the PlaylistHistory repo.](https://github.com/ClementVallois/PlaylistHistory)
